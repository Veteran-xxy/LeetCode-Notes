# 438. 找到字符串中所有字母异位词 Find All Anagrams in a String

## 一、题目理解与我的第一思路

在字符串 `s` 中，找出所有与 `p` 字符种类和次数相同的连续子串，返回它们的起始下标。字符顺序可以不同，题目中的字符串只包含小写字母。

我联想到刚做过的第 3 题，也想使用滑动窗口。这次窗口长度固定为 `p.size()`，不断向右移动。我最初想逐个判断 `p` 中的字符是否出现在窗口里，但卡在循环如何判断全部匹配、如何记录下标。

Codex 提醒我：只判断出现过不够，还要比较次数。例如 `p = "aab"`、窗口为 `"abb"`，虽然都包含 `a` 和 `b`，但不是异位词。因此可以用两个长度为 26 的数组统计字符次数。

## 二、最初代码中需要修正的地方

截图中的初稿用了 `s[i, i + n]` 截取窗口，又用了 `target.count(p[j])` 检查字符，并在检查失败时执行 `i++`。讨论中发现：

- C++ 截取字符串应使用 `s.substr(i, n)`，第二个参数是长度；`s[i, i + n]` 不是切片语法。
- `string` 没有 `.count()` 成员函数。这里需要统计各字符的次数。
- 外层条件 `i + n < s.size()` 会漏掉最后一个窗口，应包含等号。
- 窗口移动应由外层循环控制，内层再执行 `i++` 可能跳过窗口。
- 找到匹配窗口时用 `result.push_back(i)` 收集下标，不能找到一个就返回；最后统一返回答案数组。

这些是代码讨论中指出的问题，没有记录到实际编译报错。

## 三、我写出的计数版本与两处错误

按照计数建议，我先统计 `p`，再用两层循环逐个统计窗口，比较 `pcount == windowcount`。这一版中我写过：

```cpp
for (int i = 0; i + n - 1 < s.size(); i++) {
    for (int j = i; j <= i + n - 1; j++) {
        windowcount[p[j] - 'a']++;
    }
    if (pcount == windowcount) {
        result.push_back(i);
    }
}
```

第一处错误是统计了 `p[j]`，窗口其实位于 `s` 中，应统计 `s[j]`。`j` 随窗口向右移动，用它访问 `p` 还可能越界。

第二处错误是没有清空上个窗口的次数，导致不同窗口的计数累加。每次重新统计前要执行：

```cpp
fill(windowcount.begin(), windowcount.end(), 0);
```

Codex 建议把窗口范围写成 `[i, i + n)`：外层条件为 `i + n <= s.size()`，内层条件为 `j < i + n`。这样更容易看清窗口恰好有 `n` 个字符。我修改后确认这版写对了，但当时没有明确报告 AC。

## 四、从重新统计到滑动更新

重新统计每个窗口会反复处理相同字符。Codex 提出了进一步优化：相邻窗口只有一个字符移出、一个字符移入，重叠部分的计数可以保留。

我随后给出了最终滑动窗口代码，并确认通过：先同时统计 `p` 和 `s` 的第一个窗口，单独判断下标 `0`；再不断移出左侧字符、移入右侧字符，每次比较两个计数数组。

```cpp
--sCount[s[i] - 'a'];
++sCount[s[i + pLen] - 'a'];
```

这里 `i` 是移动前窗口的起点。更新后窗口范围为 `[i + 1, i + pLen + 1)`，所以匹配时保存 `i + 1`。循环条件 `i < sLen - pLen` 保证移入字符的下标 `i + pLen < sLen`。

若 `sLen < pLen`，直接返回空数组，避免初始化第一个窗口时越界。

## 五、最终代码与复杂度

最终通过的代码保存在 [solution.cpp](./solution.cpp)，不添加 `main()`，保留本次确认通过的逻辑。

设 `m = s.size()`、`n = p.size()`。重新统计窗口的版本在 `m >= n` 时需要 `O(n + (m - n + 1) × (n + 26))` 时间，通常简写为 `O(mn)`。最终版本初始化需要 `O(n)`，每次移动更新两个计数并比较固定的 26 项，时间复杂度为 `O(m + n)`。

额外空间复杂度为 `O(1)`：两个计数数组长度始终是 26。不计答案数组；若计入答案，则还需 `O(k)` 空间，`k` 为匹配窗口数量。

## 六、本题学到的 C++ 与收获

- `字符 - 'a'` 把小写字母映射到 `0` 到 `25`，可以作为计数数组下标。
- `vector<int>(26)` 会将 26 个整数初始化为 `0`，这里与 `vector<int>(26, 0)` 效果相同。
- 两个 `vector` 可以直接用 `==` 比较大小和对应元素；在这里就是比较全部字符次数。
- `fill(v.begin(), v.end(), 0)` 把已有数组元素全部重置为 `0`。
- 本题保存整数下标时，`emplace_back(i + 1)` 和 `push_back(i + 1)` 都可以。
- `return vector<int>()` 返回空的整数数组。

这题我最初就想到了固定长度窗口，但需要把“字符都出现”改成“每个字符次数都相同”。进一步优化的关键是利用相邻窗口的重叠，只维护发生变化的两个字符，而不是每次重新统计。
