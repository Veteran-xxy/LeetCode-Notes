# 128. 最长连续序列 Longest Consecutive Sequence

- 难度：Medium
- 主要知识点：哈希集合、连续序列起点
- 使用语言：C++
- 日期：2026-09-26
- 状态：已在 LeetCode 通过

## 一、题目理解

给定一个未排序的整数数组，找出数值连续的最长序列有多长。数字在原数组里不必挨着，重复数字也不能增加序列长度。题目要求时间复杂度为 `O(n)`。

## 二、我的第一思路：先排序再扫描

我先想到把数组排序，从小到大检查相邻的数：下一个数若比当前数大 1，就让计数器加一；连续关系断开时，保存目前的最大长度，再开始新的一段。

讨论中补充了两个边界：排序后可能有重复值，例如 `[1, 2, 2, 3]`，第二个 `2` 应跳过；遇到不连续的当前数时，应从这个数开始新的一段，不能直接跳到它的下一个位置。遍历结束后也要比较最后一段的长度。

这个方法有助于理解题目，但 `std::sort` 的时间复杂度是 `O(n log n)`，不满足本题要求的 `O(n)`。这里不能推广成“所有排序方法都一定是 `O(n log n)`”；只是直接使用 `std::sort` 再扫描不符合要求。

## 三、转向哈希集合

在 Codex 的提示下，我开始用 `unordered_set<int>` 去重，并快速判断某个整数是否存在。遍历集合中的 `x` 时，如果集合里有 `x - 1`，那么 `x` 不是这段序列的起点；只有找不到 `x - 1`，才从 `x` 开始向后检查 `x + 1`、`x + 2` 等数字。

我一开始以为需要先找出整个集合的最小值。后来弄清楚：集合没有固定顺序，也不需要全局最小值；每段连续序列都有自己的起点，逐个检查 `seen.count(x - 1) == 0` 即可。

遍历的是去重后的集合，而不是原数组。这样同一个起点不会因为原数组里有重复值而被反复处理。

## 四、写代码时遇到的问题

第一次写集合版本时，我只用一个 `if` 检查 `x + 1`。它最多向后走一步，无法数完更长的序列；计数器从 0 开始，也漏掉了起点本身。计数器还放在所有起点的循环之外，没有为每段序列重新计数。

第二次尝试写了 `for (int j = x; j < seen.size(); j++)`，当时反馈是 85 个用例通过了 29 个。问题是 `j` 表示整数的值，而 `seen.size()` 表示集合中的元素数量，两者不是同一类边界。例如集合只有 `{5}`，`5 < 1` 一开始就不成立。循环中即使某个数不存在，也没有立即停止，会把隔开的数字算进同一段。

这里还学到一个 C++ 细节：`size()` 返回无符号整数，负数 `j` 与它比较时可能发生无符号转换，结果不符合直觉。这个循环应由“下一个数是否存在”控制，而不是由集合大小控制。

后来 Codex 给出了 `while` 的写法。我照着修改时漏了花括号：不带 `{}` 的 `while` 只会重复执行紧跟着的一条语句，后面的 `cnt++` 不会跟着循环。花括号位置还让 `cnt` 被放到作用域之外使用。把递增语句都放入 `while`，并把最大长度的比较放在定义 `cnt` 的代码块内后，我确认这题通过了。

## 五、最终通过的代码

最终代码也保存在 [solution.cpp](./solution.cpp)：

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        int length = 0;
        unordered_set<int> seen(nums.begin(), nums.end());
        for(int x : seen){
            if(seen.count(x - 1) == 0){
                int cnt = 1;
                int current = x;
                while(seen.count(current + 1) > 0){
                    current++;
                    cnt++;
                }
                if(cnt > length){
                    length = cnt;
                }
            }
        }
        return length;
    }
};
```

每次找到起点，先把这一数算入长度；只要下一个数在集合里，就继续前进并增加长度。走到断点后，更新最大长度。空数组不会进入循环，结果保持为 0。

## 六、复杂度

平均时间复杂度为 `O(n)`：建立集合平均需要 `O(n)`，每段序列只从起点向后走一次，集合查找平均为 `O(1)`。额外空间复杂度为 `O(n)`，用于存放去重后的数字。哈希集合的 `O(1)` 查找是平均情况，不是每次操作的绝对保证。

## 七、本题学到的 C++

- `unordered_set<int> seen(nums.begin(), nums.end());` 用迭代器范围构造集合，并自动去重。
- `for (int x : seen)` 遍历集合中的值；集合的遍历顺序不固定。
- `seen.count(value)` 对集合返回 0 或 1，可用来判断一个数是否存在。
- `while` 后不加花括号时，循环体只有紧随其后的一条语句。需要一起重复的语句必须放入同一对 `{}`。
- 在 `{}` 中声明的变量只能在对应的作用域内使用；每段序列的计数器应在起点对应的代码块里重新初始化。

这题最重要的变化是：从“把所有数排好再找连续段”，改为“只从每段的起点向后数”。
