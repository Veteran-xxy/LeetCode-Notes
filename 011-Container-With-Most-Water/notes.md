# 11. 盛最多水的容器 Container With Most Water

- 难度：Medium
- 主要知识点：数组、双指针
- 使用语言：C++
- 日期：2026-09-27

## 一、题目理解

数组 `height` 中的每个数表示一条竖线的高度。选出两条线作为容器两侧，求最多能装多少水。两线下标之差是容器宽度，水面只能到较短的线，因此面积是 `(right - left) * min(height[left], height[right])`。

## 二、我的第一思路：暴力枚举

我先想到用两层循环选出所有不同的线对：`i` 选左线，`j` 从 `i + 1` 开始选右线。代码用 `if` 判断哪条线更短，以较短高度乘以 `j - i`，再更新最大面积。

```cpp
int max = 0;
int volume = 0;
for (int i = 0; i < height.size(); i++) {
    for (int j = i + 1; j < height.size(); j++) {
        if (height[i] < height[j]) {
            volume = height[i] * (j - i);
        } else {
            volume = height[j] * (j - i);
        }
        if (volume > max) {
            max = volume;
        }
    }
}
return max;
```

这段代码的面积计算是对的，但提交后**超出时间限制**。原因是它检查了所有线对，时间复杂度为 `O(n²)`；只用了几个变量，额外空间复杂度为 `O(1)`。这次遇到的是性能问题，不是面积公式或下标计算错误。

## 三、从超时到双指针

超时后，Codex 提示我从最左、最右两条线开始，并解释为什么每次可以舍弃较短的那条线。我据此自己写出了通过的双指针代码。

假设左线比右线短。保持左线不动而把右线向左移，宽度会缩小，水的高度又不会超过固定的左线，所以新面积不可能比当前面积更大。当前线对的面积已经记入最大值，就可以舍弃左线，让 `left++`。右线较短时同理，让 `right--`；两线等高时舍弃任意一边即可，我的代码走 `else`，移动右指针。

每次先用**当前**两个下标计算面积，再移动较短线对应的指针。虽然更新 `max` 的语句写在移动指针之后，它比较的 `area` 仍是移动前算出的面积，不会漏掉当前线对。

## 四、复杂度和 C++ 记录

两个指针只向中间移动，每轮至少移动一个，直到 `left >= right`，因此最终解法的时间复杂度是 `O(n)`，额外空间复杂度是 `O(1)`。

- `height.size()` 给出元素个数；非空数组的最后一个下标是 `height.size() - 1`。
- `while (left < right)` 保证每次使用的是两个不同位置的线。
- 我用 `if/else` 直接选择较短高度，与调用 `min()` 计算面积的含义相同。
- 代码中的 `max` 是合法变量名，但以后可以改叫 `maxArea` 或 `best`，避免和 `std::max` 混淆；暴力版的 `volume` 实际表示面积，叫 `area` 更准确。这些只是命名建议，不影响这次通过的代码。

这题让我看到：暴力枚举虽然容易写对，但如果能证明某些候选线对不可能带来更优答案，就可以安全地跳过它们，把两层循环优化成一次双指针遍历。
