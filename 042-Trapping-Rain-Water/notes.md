# 42. 接雨水 Trapping Rain Water

- 难度：Hard
- 主要知识点：数组、最高柱分割、双向扫描、模拟填坑
- 使用语言：C++
- 日期：2026-09-29

## 一、题目理解

数组 `height` 中的每个数字表示一根宽度为 1 的柱子的高度。低处只有被两侧更高的柱子围住时才能留下雨水。这道题需要判断哪些低处能够被填平，并累加填入的高度差。

## 二、我的第一思路：寻找右边更高的柱子

我一开始使用两层循环。外层固定当前位置 `i`，内层向右寻找高度大于等于 `height[i]` 的柱子；找到后，如果相邻位置更矮，就把高度差加入答案，并把相邻位置填到当前高度。

这个思路通过了题目展示的两个示例，但提交后只通过了 145 / 325 个测试用例。反例是：

```text
height = [4, 2, 3]
```

程序输出 `0`，正确答案是 `1`。

问题在于，我要求右边界必须满足：

```cpp
height[j] >= height[i]
```

但接住水并不要求右边的柱子一定不低于左边的柱子。这个例子中，左边的 4 和右边的 3 已经能够围住中间高度为 2 的柱子，可以把中间填到高度 3，因此水量是：

```text
min(4, 3) - 2 = 1
```

这让我意识到：不能只寻找一根不低于左边界的右柱。即使右边的柱子稍矮，也可能和左边的柱子共同围住一个坑。

## 三、我的第二个思路：以全局最高柱为界模拟填坑

我后来想到，可以先找到整个数组中的最高柱，并用它把数组分成左右两部分，然后分别进行填坑：

- 最高柱左边从左向右遍历。比较当前位置 `i` 和下一个位置 `i + 1`；如果下一格较低，就把高度差计入水量，再把下一格的高度刷新成当前高度，相当于真的把这个坑填平。
- 最高柱右边从右向左遍历。比较当前位置 `i` 和前一个位置 `i - 1`，用完全对称的方式填坑。

选择全局最高柱作为两次遍历的终点很重要：从左填时，最高柱在终点挡住水；从右填时，最高柱同样在终点挡住水。因此两侧都可以放心地朝最高柱逐格填平。

## 四、第二版代码为什么得到 11

我的第二版整体方向是对的，但寻找最高柱时把 `max` 写在了循环内部：

```cpp
for (int i = 0; i < height.size(); i++) {
    int max = 0;
    if (height[i] >= max) {
        max = height[i];
        maxindex = i;
    }
}
```

`max` 每轮循环都会重新创建并变回 0。题目中的高度都是非负数，所以条件几乎每一轮都成立，`maxindex` 最后会变成数组末尾的下标，而不是真正最高柱的下标。

对于：

```text
[0,1,0,2,1,0,1,3,2,1,2,1]
```

真正最高柱的下标是 7，但错误代码会让 `maxindex` 变成 11。程序随后一直从左向右填，把最高柱右边本来会流走的部分也算成了水，因此得到 11，而不是 6。

修正方法是把最大高度变量放到循环外，使它可以保存前面扫描过的最大值：

```cpp
int maxHeight = 0;
int maxindex = 0;

for (int i = 0; i < height.size(); i++) {
    if (height[i] >= maxHeight) {
        maxHeight = height[i];
        maxindex = i;
    }
}
```

## 五、左右扫描是怎样计算水量的

### 从左向右扫描

最高柱左边的代码是：

```cpp
for (int i = 0; i < maxindex; i++) {
    if (height[i] > height[i + 1]) {
        area += height[i] - height[i + 1];
        height[i + 1] = height[i];
    }
}
```

如果下一根柱子更矮，它上面就能接到 `height[i] - height[i + 1]` 的水。随后把 `height[i + 1]` 更新成 `height[i]`，相当于把这一格连水后的总高度向右传递。因此，扫描过程中当前的 `height[i]` 实际代表“截至当前位置，左边出现过的最高高度”。

如果下一根柱子更高，就不加水；它自然会成为后续位置新的左侧最高柱。

### 从右向左扫描

最高柱右边完全对称：

```cpp
for (int i = height.size() - 1; i > maxindex; i--) {
    if (height[i] > height[i - 1]) {
        area += height[i] - height[i - 1];
        height[i - 1] = height[i];
    }
}
```

此时修改 `height[i - 1]`，相当于把从右侧扫描到的最高高度向左传递。

## 六、最终代码

最终代码也保存在 [solution.cpp](./solution.cpp)：

```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int area = 0;
        int maxindex = 0;
        int maxHeight = 0;

        for (int i = 0; i < height.size(); i++) {
            if (height[i] >= maxHeight) {
                maxHeight = height[i];
                maxindex = i;
            }
        }

        for (int i = 0; i < maxindex; i++) {
            if (height[i] > height[i + 1]) {
                area += height[i] - height[i + 1];
                height[i + 1] = height[i];
            }
        }

        for (int i = height.size() - 1; i > maxindex; i--) {
            if (height[i] > height[i - 1]) {
                area += height[i] - height[i - 1];
                height[i - 1] = height[i];
            }
        }

        return area;
    }
};
```

## 七、复杂度分析

- 时间复杂度：`O(n)`。寻找最高柱、从左向右扫描、从右向左扫描都只需要线性时间。
- 额外空间复杂度：`O(1)`。只使用了几个变量，不过代码会直接修改输入数组 `height`。

## 八、本题学到的 C++ 与编程细节

### 变量的作用域和生命周期

在循环体内部声明的变量，每次进入循环体时都会重新创建。需要在多轮循环之间保存的最大值，必须在循环外声明。

### 不建议把变量命名为 `max`

虽然这里通常可以编译，但标准库中也有常用的 `std::max`。使用 `maxHeight` 既能准确表达含义，也能减少命名冲突和阅读歧义。

### 修改引用参数会影响原数组

参数是 `vector<int>& height`，代码中的赋值会直接修改传入的数组。这道题允许这样做，而且能够把额外空间保持在 `O(1)`；如果后续还需要保留原数组，就不能直接使用这种写法。

## 九、本题最重要的收获

我的第二个思路并没有错，真正的问题只是最大值变量放错了位置。调试时不能因为结果错误就立刻否定整个算法，可以先分别检查：算法的核心依据是否成立，以及代码有没有正确维护它需要的状态。

这道题的关键转化是先用全局最高柱把数组分成两边，再从两端朝最高柱模拟填坑。每填一格就立即刷新它的高度，于是填平后的结果可以继续参与下一格的比较，不需要额外数组记录状态。
